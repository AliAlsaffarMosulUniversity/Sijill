# سجلّ النسخة البحثية الثانية

الشفرة متاحة للمراجعة على https://github.com/AliAlsaffarMosulUniversity/Sijill . الإصدار 2.1.0-research مخصص للتحقق العلمي، ولم ينفذ عليه تقييم مشاركين في هذا التحديث.

هذه حزمة تحديث فعلية للمصدر ذي الحيوية، بعد مقارنته بمصدر كلاود الأصلي والتقييمين والبحث المعدل. ليست نظام حضور معتمداً أو إثباتاً على فعالية الحيوية.

## التشغيل

فك الحزمة واحتفظ بملفات index.html وmodels وvendor معاً. شغل START_LOCAL.cmd بوجود Python 3 ثم افتح http://127.0.0.1:8765 في Chrome أو Edge. إذا لم يوجد الأمر py، استخدم python -m http.server 8765 --bind 127.0.0.1 من مجلد الحزمة. لا يتصل التطبيق بمضيف خارجي لتحميل المكتبة أو النماذج. لا يحتاج npm لتشغيل التطبيق.

## التثبيت والعمل دون إنترنت

اضغط «تثبيت التطبيق» أو افتح «طريقة التثبيت وحماية البيانات» داخل الواجهة لتعليمات Android وiPhone وiPad والحاسوب. انتظر رسالة جاهز للعمل دون إنترنت واكتمال 15 من 15 ملفاً قبل فصل الشبكة. أول تحميل أو جهاز جديد أو مسح بيانات الموقع يحتاج اتصالاً أو نسخة ملفات التشغيل على خادم محلي. دعم التثبيت والكاميرا يختلف بين المتصفحات والأجهزة؛ لا ندعي التحقق على كل الأجهزة.

تخزن السجلات وسمات الوجه في localStorage على الجهاز، وملفات التشغيل والنماذج في Cache Storage. البيانات لا تنتقل بين الأجهزة تلقائياً ولا ترفع إلى GitHub. صدّر نسخة احتياطية مشفرة من الإعدادات واحفظها خارج الجهاز مع حفظ كلمة المرور منفصلة. عند فقده يمكن تشغيل التطبيق على جهاز متوافق آخر واستيراد النسخة؛ دون النسخة وكلمة مرورها لا يمكن استرجاع البيانات المحلية. العمل دون إنترنت لا يعالج وحده فقد الجهاز أو غياب المزامنة.

## التحديثات

المكتبة وأوزان النماذج أصبحت محلية. أضيف قسم تقييم بحثي يحفظ محاولة واحدة لكل ضغطة بدء، بما فيها عدم اكتشاف الوجه، ويسجل الهوية المرجعية والعتبة والمسافة والقرار والتوقيت والظروف والجهاز ودقة الكاميرا. يمنع تغيير إعدادات المحاولة أثناء تنفيذها، ويفصل نتائج التجربة عن الحضور الرسمي. أصلح التاريخ المحلي، ومنع تقدم الحيوية بإطار لا يطابق الهوية، ومنع قبول التحدي بعد انتهاء مهلته، وأوقف حفظ الصور المصغرة الجديدة، وأبطل وصف الوجه السابق عند فشل التقاط صورة جديدة. أضيفت نسخ احتياطية مشفرة تشمل الحضور والتجارب، وحذف شامل، وحماية من تفسير خلايا CSV كصيغ.

ملف analyze_results.py يحلل سجل البحث باستخدام Python القياسي. شغله عبر python analyze_results.py sijill_research.csv ثم احفظ الناتج في ملف JSON. لا تدمج ملفين صادرين يحويان المحاولات نفسها؛ يرفض المحلل تكرار trial_id. البيانات الاصطناعية المستخدمة في اختبارات الشيفرة ليست نتائج مشاركين.

## القيود

localStorage وCSV غير مشفرين؛ تشفير النسخ الاحتياطية لا يحميهما. لا توجد حسابات دخول أو صلاحيات أو تشفير على مستوى التطبيق للقاعدة التشغيلية. الحذف من المتصفح لا يحذف الملفات المصدرة. الصورة القديمة قد تبقى في قاعدة قديمة أو نسخة مستوردة. استخدم رموزاً وجهازاً مشفراً ومقيد الوصول، وجدول احتفاظ معتمداً وموافقة خطية طوعية وقرار لجنة قبل جمع بيانات جديدة.

صورة تسجيل واحدة لكل هوية؛ لا شعب أو صلاحيات متقدمة أو تقارير فصلية أو ربط معلومات طلاب. الحيوية معالم تجريبية قد تنخدع بالفيديو أو تحريك الصور. لا توجد نتائج تثبت مقاومتها. الأزمنة المسجلة لها تعريفات مختلفة موضحة في البروتوكول؛ ليست بديلاً عن مقارنة جلسات يدوية كاملة. المتصفح قد يفقد محاولة أثناء انقطاع الكهرباء؛ طابق خطة الترتيب مع الصفوف.

الملفات القديمة ذات النسخ الاحتياطية غير المشفرة لا تستورد مباشرة في هذه النسخة. احتفظ بها تحت حماية حتى يقرر مسؤول البيانات جواز ترحيلها، ولا تحوّل صيغة الملف يدوياً بلا تحقق. تصدير تقرير الحضور القديم بصيغة doc هو HTML قابل للفتح في Word وليس مستند docx أصلياً.

## إعادة الاختبارات

اختبارات decisions تحتاج Node وPlaywright ومتصفح Edge. شغل node tests/test_app.cjs من مجلد الحزمة بعد تجهيز Playwright في بيئة تطوير منفصلة. لا تحتاج هذه المتطلبات للتشغيل العادي. اختبارات التحليل ومظاهر النماذج تحتاج Python القياسي: python tests/test_analysis.py. انظر TEST_REPORT.md للتغطية الفعلية وحدودها.

## الملفات المساندة

manual_comparison.csv قالب فارغ لمقارنة الجلسات؛ لا يتضمن نتائج. provenance.json يثبت بصمات المدخلات الأصلية. SHA256SUMS.txt يثبت بصمات الإصدار الناتج. MODEL_PROVENANCE.md يوضح مصادر الأوزان وترخيص المكتبة. المستودع العام مخصص للشفرة والأدوات ووثائق التشغيل؛ لا توجد بيانات مشاركين أو كتب موافقة أو توقيعات في هذه الحزمة.
